# ⏰ 正念 (woofish)

基于 **Kotlin + Jetpack Compose + Material 3** 构建的现代化、极简禅意风安卓电子木鱼与律动修行应用。

---

## ✨ 核心特性

- ⏳ **专注倒计时（定时停止）系统**：
  - 自动节拍器设置中内置倒计时开关，预设 5、10、15、20、30、45、60 分钟常用专注时长（支持 1~180 分钟自定义）；
  - 倒计时归零时自动停止敲击，并触发禅意提示音与双段触觉震动；
  - 首页副标题下方常驻精致微光倒计时胶囊（如 `⏱️ 倒计时 14:32`），支持点击直达设置。
- 🎚️ **自定义节拍速度（滑杆 + 1 步进加减微调）**：
  - 底部“自定义”窗口全新重构，提供 30~300 BPM 节拍速度设置滑杆；
  - 左右两侧配备专属 `[-]` 和 `[+]` 实体按钮，支持以 1 BPM 为单位的精准微调；
  - 大字数值、微调按钮、滑杆与直接输入框三向无缝实时联动。
- 🎛️ **自动节拍器设置弹窗精简与纯中文测速**：
  - 移除冗余的预设按钮与滑杆，专注倒计时控制与音频节奏分析；
  - 测速交互全面汉化，去除英文后缀（“🖐️ 点击测速”）。
- ✨ **主界面交互升级**：
  - 底部 6 档速度快捷按钮在当前运行档位下呈现半透明暖金背景微光，播放状态一目了然；
  - 中央超大功德/击打计数字符支持长按快捷清零，日常操作免去繁琐设置。
- 🎯 **极致纯净**：桌面应用与安装包名称统一为“**正念**”，无广告、无冗余外链、无任何操作提示，保留最纯粹的心灵修行体验。
- ⏰ **全新禅意钟表图标**：设计了纯黑底色 + 极简纯白钟表（10:10 舒展微笑指针与金轴点）的 Android Adaptive Icon 自适应图标。
- ⚡ **打击零延迟（触碰即响）**：
  - 基于 Touch DOWN 瞬间监听，手指触碰屏幕的纳秒瞬间立即发声，告别传统点击抬手的滞后感；
  - 开启底层 `FLAG_LOW_LATENCY` 硬件加速通道。
- 🎛️ **三大经典模式随心切换（设置内收纳）**：
  - **🐟 木鱼模式**：开箱默认模式，包含禅韵木鱼（默认）、沉厚木鱼、清脆木鱼 3 款高品质无损音效，速度预设重构为“禅修 30、沉静 60、舒缓 90、诵经 120、精进 150”；
  - **⏱️ 节拍器模式**：圆润纯白大底座机身，中间纯黑粗线条摆杆在机身白区范围内一左一右乒乓往复摆动，绝不越界；
  - **🥁 电子鼓模式**：圆润纯白实心极简鼓身剪影（无内圈黑线），包含低音鼓 (Kick)、真实鼓心敲击手鼓（Djembe Bass）、非洲鼓 (Djembe) 3 款打击音效。
- ⚡ **主界面 6 档自动敲击直控**：
  - 屏幕下方常驻 6 个加大速度开关（48dp 高度，13.5sp 字体）：`30`、`60`、`90`、`120`、`150` 与 `自定义`，随模式呈现差异化命名；
  - 采用极简灰色边框、纯白文字、透明底色设计，点击一键开/关/切换，且支持跟随清屏模式优雅隐退。
- 🛑 **自动敲击不计数与防误触隔离**：自动敲击进行中，专注节奏发声与动效，不累加计数器；轻触屏幕任意区域立即停止自动敲击且不发声，纯粹记录手动敲击。
- 🛡️ **触控防抖与双响连响根治**：引入 50ms 硬件接触滤波与显式事件消费，杜绝手机电容屏物理微抖造成的二次误触发。
- 📳 **敲击震动 0~500ms 无级滑块调节**：
  - 设置内支持 0（关闭）~ 500ms 自由调节震感，默认 120ms，层级位于背景音乐下方；
  - 底层满功率强动能输出，即使将手机平放桌面上用手指轻敲屏幕，桌面亦能传来清晰切实的物理机械敲击震颤。
- 💖 **自愿随喜赞助**：设置页底部提供随喜赞助二维码，用户可自愿选择是否支持项目持续维护。
- 🎵 **高精度环境音乐测速（听音识速）**：
  - 采用 2 阶 IIR 巴特沃斯低通滤波器（聚焦 180Hz 底鼓低音骨架）+ 自适应瞬态上升沿提取 + 谐波梳状加权自相关分析 + 直方图投票平滑稳定器，彻底消除八度跳跃与杂音跳变。
- 🏷️ **计时/计数副标题方案**：预设“正念”、“计时”、“功德”、“节拍”、“律动”、“计数”等常用标签，支持一键切换或输入任意自定义文字，输入框紧凑精炼。
- 🛡️ **等宽数字排版稳定防抖**：采用等宽字体与表格数字特性（`tnum`），数字递增时位置稳固如山，彻底消除左右晃动。
- 🎵 **本地自定义背景音乐**：
  - 点击左上角音乐按钮直接选择手机本地音频文件（MP3 / WAV / FLAC 等）作为背景音乐；
  - **纯应用内播放**：完全在软件内部循环播放与音量调节，绝不跳出至外部播放器；
  - **零敏感权限**：采用系统原生文件选择框架，不申请敏感危险权限，安全合规，并支持长期记忆已选音频。
- 📱 **默认全屏敲击模式**：启动时默认开启全屏点击，手指触碰屏幕任意空白区域均可正常触发击打。
- 👁️ **沉浸清屏模式**：点击右上角【清屏】后，仅清除屏幕中心的计数与文字及下部直控按钮，顶栏按钮完整保留常驻。
- ✨ **固态实木物理打击动效**：去除果冻史莱姆般的横向拉伸变形，呈现真实硬木微下沉（4dp）与无迟滞坚硬回弹。

## 🛠️ 技术栈

- **应用名称**：`正念` (woofish)
- **当前版本**：`v0.13.0`
- **语言**：Kotlin 2.0
- **UI 框架**：Jetpack Compose (Material 3)
- **音频引擎**：`SoundPool`（低延迟打击音效池） + `MediaPlayer`（本地 Uri BGM 循环播放）
- **触觉反馈**：`Vibrator` / `VibrationEffect`（0~500ms 满幅物理驱动）
- **CI/CD 自动化**：GitHub Actions 自动构建与发布 Release，生成 `woofish-0.13.0.apk`
