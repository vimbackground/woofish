## 🌿 什么是「正念」？

在忙碌喧嚣的日常与工作间隙，给心灵留出一片清净。

**正念 (woofish)** 是一款面向全场景的极简正念修行与效率律动工具。无论是敲击木鱼积攒功德、番茄钟沉浸深度专注、听音节拍辅助乐器律动，还是在治愈白噪音与心跳声中小憩解压，它都能为你提供温润、稳定且无任何打扰的纯粹陪伴。

---

## ✨ 核心特色与功能

### 🐟 电子木鱼 · 凝神解压
- **精选真实木质原声**：内置禅韵木鱼、沉厚木鱼、清脆木鱼等高品质原声，触碰即响、清透温润。
- **清爽机械震感**：全新调优的轻灵物理触觉反馈（默认 40ms，支持 0~120ms 滑块精确调节并配备两翼 `−`/`+` 微调按键）。
- **经典节奏与独立记忆**：内置 5 档经典预设节奏（禅修、沉静、舒缓、诵经、精进），支持自定义持续时间与时长独立记忆。
- **功德计数统计**：自动统计敲击总数，支持在主界面长按大字快速清零计数。

### 🍅 禅意番茄钟 · 深度专注工作法
- **极简沉浸表盘**：纯黑背景与纯白钟面指针，去除一切不必要干扰。
- **专注原生音效矩阵**：
  - **白噪音**：基于圆周频域合成（Circular IFFT）打造的数学级无缝循环纯净白噪，零卡顿咔哒杂音，平滑护耳；
  - **沉浸雨声**：自然降雨实录原声，等功率交叉淡化平滑无限循环，营造安心深思氛围；
  - **治愈秒针音**：轻柔走针滴答声，伴随时光流动专注前行（支持一键静音）。
- **3x3 科学专注矩阵**：预设 9 款经典阶段模版（`2分钟`、`1+1分钟`、`15+5分钟`、`5分钟`、`4+1分钟`、`25+5分钟`、`8分钟`、`6+2分钟`、`50+10分钟`）。
- **自定义多阶段连续规划**：支持无限阶段自由连缀（如 `5+2+1`、`25+5+25+15`），自动平滑流转并配备分步轻提示声。

### ⏱️ 节拍器与打击手鼓 · 专业律动
- **机械式节拍器**：复刻经典黑白往复物理摆针，支持 30~300 BPM 极宽量程调速，配备单拍秒数即时换算。
- **真实木质手鼓**：非洲手鼓等原声音色采样，纯正通透。
- **智能节拍测速**：
  - **Tap Tempo 指尖测速**：轻点屏幕即可快速测算拍速；
  - **智能环境拾音**：实时识别麦克风采集的环境节拍并自动同步。

### 🔄 全向横竖屏适配与屏幕方向掌控
- **横屏模式深度重塑**：左侧 50% 居中展示大字计数/计时，右侧 50% 居中展示乐器图示，底部单排平铺 6 项直控按钮，平板/车载桌面横放更加协调大气。
- **屏幕方向随心切换**：设置中内置“自动旋转”、“锁定竖屏”、“锁定横屏”三档开关，满足不同使用姿势与底座摆放需求。
- **全机型动态响应排版**：无论超长大屏、折叠屏还是紧凑小屏设备，字号、内边距与图示智能等比缩放，所有弹窗配备滚动流保护，彻底告别元素越界与拥挤遮挡。

### 🧘 清屏沉浸与个性定制
- **清屏模式微光指示**：一键隐藏繁杂控制，仅保留核心图腾与悬浮暂停胶囊，微光细腻显示实时节奏或番茄钟执行阶段。
- **随身背景音乐 (BGM)**：支持导入本地轻音乐、雨声、溪流音频，在软件内无限循环伴奏。
- **个性化定制文案**：自由设定主界面寄语（如“正念”、“功德”、“专注”、“平静”）。

<details>
<summary>🛠️ 开发者指南 (架构、技术栈与本地构建)</summary>

### 技术栈与工程架构
- **开发语言**：Kotlin 2.0
- **UI 框架**：Jetpack Compose Multiplatform (Material 3)
- **工程结构**：
  - `:shared`：跨平台核心业务逻辑、ViewModel、UI 界面及音频合成引擎
  - `:app`：Android 原生宿主壳工程、权限管理与硬件音频/触觉通道接入
- **音频引擎**：Android SoundPool 原生低延迟通道 + 自研 Circular IFFT 无缝音频循环技术
- **包体精简**：Google R8 深度代码混淆裁剪与无损音频压缩，极致控制安装包体积

### 本地构建指南
在仓库根目录下运行（需配置 JDK 17 与 Android SDK）：
```bash
# 编译并打包 Release APK (产物将归档至 _Dist/android/ 目录)
./gradlew :app:assembleRelease

# 或使用一键自动化构建脚本
./build_local.ps1
```
