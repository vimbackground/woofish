# ⏰ 正念 (woofish)

基于 **Kotlin + Jetpack Compose + Material 3** 构建的现代化、极简禅意风安卓电子木鱼与律动修行应用。

---

## ✨ 核心特性

- 🎯 **极致纯净**：桌面应用与安装包名称统一为“**正念**”，无广告、无冗余外链、无任何操作提示，保留最纯粹的心灵修行体验。
- ⏰ **全新禅意钟表图标**：设计了纯黑底色 + 极简纯白钟表（10:10 舒展微笑指针与金轴点）的 Android Adaptive Icon 自适应图标。
- ⚡ **打击零延迟（触碰即响）**：
  - 基于 Touch DOWN 瞬间监听，手指触碰屏幕的纳秒瞬间立即发声，告别传统点击抬手的滞后感；
  - 开启底层 `FLAG_LOW_LATENCY` 硬件加速通道。
- 🎛️ **四大模式随心切换（设置内收纳）**：
  - **🐟 木鱼模式**：开箱默认模式，包含禅韵木鱼（默认）、沉厚木鱼、清脆木鱼 3 款高品质无损音效，速度预设重构为“禅修 30、沉静 60、舒缓 90、诵经 120、精进 150”；
  - **⏱️ 节拍器模式**：圆润白底机身与纯黑粗线条摆杆反显，支持一拍在左、一拍在右左右平滑乒乓往复摆动；
  - **🥁 电子鼓模式**：圆润白底一体化极简打击垫，包含低音鼓 (Kick)、手鼓、非洲鼓 (Djembe) 3 款打击音效；
  - **🎉 活动模式**：专为集体团建、体育助威与活动聚会打造，内置“整齐拍掌”、“集体喊加油”、“集体怒吼” 3 款专属音频与击节矢量图标。
- ⚡ **主界面 6 档自动敲击直控**：
  - 屏幕下方常驻 6 个加大速度开关（48dp 高度，13.5sp 字体）：`30`、`60`、`90`、`120`、`150` 与 `自定义`，随模式呈现差异化命名；
  - 采用极简灰色边框、纯白文字、透明底色设计，点击一键开/关/切换，且支持跟随清屏模式优雅隐退。
- 🛑 **自动敲击触屏防误触**：自动敲击进行中，轻触屏幕任意区域立即停止自动敲击且完全不发声；非自动敲击状态下才为手动敲击。
- 📳 **手动敲击专属真实震感**：手动敲击触发系统底层 `EFFECT_HEAVY_CLICK` 专属重击触感反馈，还原木槌硬木受力与真实阻尼感。
- 🎵 **高精度环境音乐测速（听音识速）**：
  - 采用 2 阶 IIR 巴特沃斯低通滤波器（聚焦 180Hz 底鼓低音骨架）+ 自适应瞬态上升沿提取 + 谐波梳状加权自相关分析 + 直方图投票平滑稳定器，彻底消除八度跳跃与杂音跳变。
- 🏷️ **计数副标题方案**：预设“正念”、“功德”、“节拍”、“律动”、“加油”、“助威”、“计数”等常用标签，支持一键切换或输入任意自定义文字。
- 🛡️ **等宽数字排版稳定防抖**：采用等宽字体与表格数字特性（`tnum`），数字递增时位置稳固如山，彻底消除左右晃动。
- 🎵 **本地自定义背景音乐**：
  - 点击左上角音乐按钮直接选择手机本地音频文件（MP3 / WAV / FLAC 等）作为背景音乐；
  - **纯应用内播放**：完全在软件内部循环播放与音量调节，绝不跳出至外部播放器；
  - **零敏感权限**：采用系统原生文件选择框架，不申请敏感危险权限，安全合规，并支持长期记忆已选音频。
- 📱 **默认全屏敲击模式**：启动时默认开启全屏点击，手指触碰屏幕任意空白区域均可正常触发击打。
- 👁️ **沉浸清屏模式**：点击右上角【清屏】后，仅清除屏幕中心的计数与文字及下部直控按钮，顶栏按钮完整保留常驻。
- ✨ **固态实木物理打击动效**：去除果冻史莱姆般的横向拉伸变形，呈现真实硬木微下沉（4dp）与无迟滞坚硬回弹。

## 🛠️ 技术栈

- **应用名称**：`正念` (woofish)
- **当前版本**：`v0.10.0`
- **语言**：Kotlin 2.0
- **UI 框架**：Jetpack Compose (Material 3)
- **音频引擎**：`SoundPool`（低延迟打击音效池） + `MediaPlayer`（本地 Uri BGM 循环播放）
- **触觉反馈**：`Vibrator` / `VibrationEffect`
- **CI/CD 自动化**：GitHub Actions 自动构建与发布 Release，生成 `woofish-0.10.0.apk`
