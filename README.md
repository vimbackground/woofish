# ⏰ 正念 (woofish)

基于 **Kotlin + Jetpack Compose + Material 3** 构建的现代化、极简禅意风安卓电子木鱼与律动修行应用。

---

## ✨ 核心特性

- 🎯 **极致纯净**：桌面应用与安装包名称统一为“**正念**”，无广告、无冗余外链、无任何操作提示，保留最纯粹的心灵修行体验。
- ⏰ **全新禅意钟表图标**：设计了纯黑底色 + 极简纯白钟表（10:10 舒展微笑指针与金轴点）的 Android Adaptive Icon 自适应图标。
- ⚡ **打击零延迟（触碰即响）**：
  - 基于 Touch DOWN 瞬间监听，手指触碰屏幕的纳秒瞬间立即发声并产生物理弹性形变，告别传统点击抬手的滞后感；
  - 开启底层 `FLAG_LOW_LATENCY` 硬件加速通道。
- 🎛️ **三大模式随心切换（设置内收纳）**：
  - **🐟 木鱼模式**：经典木鱼矢量图，包含木鱼原声、清脆木鱼 2 款音效；
  - **⏱️ 节拍器模式**：机械金字塔摆杆矢量图，包含机械清脆高音、木质节拍 2 款音效；
  - **🥁 电子鼓模式**：乐器鼓矢量图，包含低音鼓 (Kick)、中式大堂鼓、非洲手鼓 (Djembe) 3 款打击音效；
  - 顶栏音效按钮只在当前模式的专属音效间循环切换。
- 🎵 **音乐节拍器（BPM）与手动输入**：
  - 自动节奏全面支持 **BPM（每分钟拍数，30 ~ 240）** 调节；
  - 提供常用音乐速度预设：60 慢板/禅定、80 行板/舒缓、100 中板、120 快板；
  - **支持手动输入数字**：点击“自定义”或 BPM 标签，直接呼出数字键盘输入具体拍数。
- 🛡️ **等宽数字排版稳定防抖**：采用等宽字体与表格数字特性（`tnum`），数字递增时位置稳固如山，彻底消除左右晃动。
- 🏷️ **计数副标题自定义**：默认文案为“正念”，可在设置弹窗中自定义修改为“功德”、“节拍”、“律动”等并持久化保存。
- 🎵 **本地自定义背景音乐**：
  - 点击左上角音乐按钮直接选择手机本地音频文件（MP3 / WAV / FLAC 等）作为背景音乐；
  - **纯应用内播放**：完全在软件内部循环播放与音量调节，绝不跳出至外部播放器；
  - **零敏感权限**：采用系统原生文件选择框架，不申请敏感危险权限，安全合规，并支持长期记忆已选音频。
- 📱 **默认全屏敲击模式**：启动时默认开启全屏点击，手指触碰屏幕任意空白区域均可正常触发击打。
- 👁️ **沉浸清屏模式**：点击右上角【清屏】后，仅清除屏幕中心的计数与文字，顶栏按钮完整保留常驻。
- ✨ **真实物理打击动效**：受力下压、挤压形变（拉伸 X，压缩 Y）配合高阻尼弹簧回弹与轻微触觉震动。

---

## 🛠️ 技术栈

- **应用名称**：`正念` (woofish)
- **当前版本**：`v0.7.0`
- **语言**：Kotlin 2.0
- **UI 框架**：Jetpack Compose (Material 3)
- **音频引擎**：`SoundPool`（低延迟打击音效池） + `MediaPlayer`（本地 Uri BGM 循环播放）
- **触觉反馈**：`Vibrator` / `VibrationEffect`
- **CI/CD 自动化**：GitHub Actions 自动构建与发布 Release，生成 `正念.apk`

本项目重构自开源项目：[**WoodenFish (by Ares-Chang)**](https://github.com/ares-chang/wooden-fish)。

原项目采用 SolidJS + Vite 开发，现已完全重构为基于 Kotlin + Jetpack Compose 的 Android 原生应用，并针对移动端手感、沉浸清屏体验和极简交互进行了全面升级。
